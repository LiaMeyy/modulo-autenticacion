# Módulo de Autenticación 

Este repositorio contiene el trabajo del módulo de autenticación. Aquí estamos organizando todo lo relacionado con el proyecto, incluyendo las historias de usuario, el proyecto en GitHub y el proceso con ramas, commits y merges.

Objetivo del proyecto
Implementar un sistema básico de autenticación donde un usuario pueda registrarse, iniciar sesión, recuperar su contraseña y cerrar sesión. La idea es entender cómo funciona el flujo y cómo se organiza el trabajo usando GitHub.

Integrantes del equipo
- Lía
- Integrante 2
- Integrante 3

Funcionalidades principales
- Registro de usuario
- Inicio de sesión
- Recuperación de contraseña
- Cierre de sesión

Historias de usuario
1. Como usuario, quiero registrarme para poder crear una cuenta.
2. Como usuario registrado, quiero iniciar sesión para entrar a mi cuenta.
3. Como usuario, quiero poder recuperar mi contraseña si la olvido.
4. Como usuario, quiero cerrar sesión para salir del sistema.

Flujo de trabajo
Se trabaja con las siguientes ramas:

- main: rama principal donde va lo final.
- develop: rama donde se integra lo que se va avanzando.
- feature/nombre: ramas para cada funcionalidad.

Lo que aprendí:
En este proyecto aprendí a organizar mejor el trabajo usando GitHub, especialmente el manejo de ramas, issues, pull requests y el uso del Project. También entendí la importancia de planear antes de empezar a programar y dividir las tareas para que todo sea más fácil de manejar.
